Before you install

A few
common questions.

Do I need an account?+

No. Studio runs locally, with projects and assets in your workspace. The source is free and open.

Can I use it offline?+

The app bundles its editor, fonts, template previews, and shader code. Initial source setup needs downloads; external AI connections need the network used by your client.

Which formats can I export?+

Templates export MP4, GIF, WebM, MOV, and PNG. Shaders export PNG stills and short WebM recordings. PNG and GIF are silent.

Does it work on macOS and Linux?+

The source launcher supports Windows, macOS, and Linux. On macOS and Linux, install Cairo and Pango as described in the setup guide. The packaged desktop installer is for Windows.

Do I need LaTeX?+

The ready-made templates use ordinary text. LaTeX is optional for custom scenes that use mathematical typesetting.
